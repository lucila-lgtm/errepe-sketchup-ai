# ERREPÉ SketchUp AI

Puente entre lenguaje natural, escenas estructuradas y generación de archivos SketchUp.

## Objetivo

1. Describir un evento o espacio.
2. Convertirlo en una escena estructurada.
3. Editar medidas y objetos.
4. Enviar la escena a un worker con SketchUp SDK.
5. Descargar un archivo .skp compatible con SketchUp Web.

## Estado

MVP inicial. El generador SKP real se conectará mediante un worker separado que use el SDK oficial de SketchUp.
